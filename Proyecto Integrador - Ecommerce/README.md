## Tecnologías a utilizar (Enfoque Simple)
Para agilizar el desarrollo, se utilizará el ecosistema de JavaScript en todo el proyecto:
* **Frontend:** HTML, CSS y JavaScript Vanilla (sin frameworks adicionales).
* **Backend:** Node.js con Express.js.
* **Base de Datos:** MySQL o PostgreSQL.
* **Autenticación:** JWT (JSON Web Tokens) en Node.js.
* **Pasarela de Pagos:** SDK oficial de Mercado Pago para Node.js.
* **Deploy:** Render (para el Backend y BD) y Vercel (para el Frontend).

## Propósito del proyecto
Desarrollar una plataforma de comercio electrónico (E-commerce) B2C enfocada en la venta de vinos y productos de bodegas boutique. El sistema permitirá a los clientes explorar un catálogo, gestionar su carrito de compras de forma nativa, registrarse de manera segura y finalizar sus pedidos integrando el checkout de Mercado Pago.
